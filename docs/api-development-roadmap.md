# API Development Roadmap

## Phase 1: Backend Foundation (Completed)
- Directory structure, Express app, MongoDB connection, central error handling, JWT foundation, logging, Zod validation.

## Phase 2: Auth + RBAC
- User model, authentication workflows (register, login, refresh tokens), and RBAC implementation.

## Phase 3: Brands
- CRUD APIs for vehicle brands.

## Phase 4: Models
- CRUD APIs for vehicle models (linked to brands).

## Phase 5: Generations
- CRUD APIs for vehicle generations (linked to models).

## Phase 6: Variants
- CRUD APIs for vehicle variants (linked to generations).

## Phase 7: Markets
- Define sales markets (countries/regions).

## Phase 8: Variant Markets + Pricing
- Map variants to markets with specific pricing data.

## Phase 9: Specifications
- Detailed technical specs for variants.

## Phase 10: Features
- Equipment and features linked to variants.

## Phase 11: Colors
- Exterior and interior color options.


## Phase 12: Media + AWS S3
- Image uploads to S3, linking media to catalog entities.

*(Further phases are documented in the main project requirements)*
